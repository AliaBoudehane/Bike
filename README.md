# Biking traffic in Paris

## Overview
The City of Paris has been deploying permanent bicycle counters for several years to monitor the growth and usage of cycling infrastructure. This project aims to analyze the data collected by these counters to visualize peak cycling times and areas with the highest traffic.

## Objective
The main goal of this project is to analyze and visualize bicycle traffic data, identifying peak usage hours and areas with high cycling activity. We have also integrated weather data to compare cycling patterns under different weather conditions. The results will serve as valuable tools for the Paris City Hall, enabling informed decisions on how to improve cycling infrastructure and promote safer, more efficient bike routes throughout the city.

## Key Features
Analysis of bicycle traffic patterns

Visualization of peak hours and high-traffic areas

Integration of weather data for comparison

Decision-making tools for urban planning and infrastructure improvement

Note: The analysis is conducted in French.
